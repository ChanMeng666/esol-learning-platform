# Documentation

This directory contains all technical documentation for the NZCEL ESOL Learning Platform.

## Structure

### 📐 Architecture (`architecture/`)
Technical architecture and database design documentation:
- **DATABASE_ARCHITECTURE.md** - Complete database schema, ERD diagrams, Server Actions catalog, data flow patterns
- **DATABASE_SCHEMA_IMPLEMENTATION.md** - Implementation guide with real-world integration examples

### 🎯 Features (`features/`)
Feature implementation documentation:
- **TEACHER_FEATURES_IMPLEMENTATION.md** - Teacher platform features and implementation

### 🐛 Fixes (`fixes/`)
Bug fixes and issue resolutions:
- **BUG_FIXES.md** - Authentication and role-based access fixes
- **PARENT_ROLE_FIX.md** - Parent dashboard access fix

### 📖 Guides (`guides/`)
Implementation guides and user documentation:
- **STACK_AUTH_INTEGRATION.md** - Stack Auth setup and migration guide
- **OPENAI_REALTIME_IMPLEMENTATION_GUIDE.md** - OpenAI Realtime API integration guide
- **INVITATION_CODE_SYSTEM.md** - Invitation code system complete guide
- **INVITATION_CODES.md** - Quick reference for invitation codes
- **USER_CLEANUP_GUIDE.md** - User data cleanup procedures
- **IMPLEMENTATION_COMPLETE.md** - Feature implementation completion status
- **PROJECT_SUMMARY.md** - High-level project overview

### 🔄 Migration (`migration/`)
Database and architecture migration guides:
- **MULTI_TENANT_MIGRATION_GUIDE.md** - Multi-tenant architecture migration guide

### 🧪 Testing (`testing/`)
Testing documentation and guides:
- **QUICK_TEST_GUIDE.md** - Quick testing guide for bug fixes verification
- **TESTING_GUIDE.md** - Complete account creation and testing guide
